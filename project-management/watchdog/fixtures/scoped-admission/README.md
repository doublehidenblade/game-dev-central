# Scoped-source test evidence

This directory contains **test controls**, not admission for a live task. No
private queue/session observations or actionable live decision receipts are
published. No Actions or deployment was run.

## Synthetic regression

`synthetic-snapshot.json` is generated by `test_scoped_admission.docs_case()`.
Every actor, request, source receipt and repository in it is synthetic. Its
canonical criteria are document-only, build-null, nonvisual and declare no
invented unit/gameplay tests. The generator actually executes the unchanged
`evidence_policy.evaluate_completion` before recording the one required check,
`evidence-policy:acceptance-check`. This is an executed **fixture** check, not a
claim that any live task passed.

The production evaluator checks real SHA-1 Git commit/tree/blob membership,
ancestry and full path deltas in these fixtures. Tests cover unknown/overlapping
branches and sibling PRs, proved ancestor/disjoint branches, row identity/context/
order/mode, current-base dependency drift, missing or stale scoped receipts,
changed source inventory, owners/queues/dependencies/stops/provider denials,
required-check failure, independent review, current rule acknowledgment,
exact-decision invalidation, original global unknown behavior, every supported
CLI/imported alias, and preservation of the old no-scope route.

Run from repository root:

    python3 -m unittest discover -s project-management/watchdog -p test_scoped_admission.py -v

For the fixture's historical clock only, direct replay is:

    python3 -c 'import sys,json; sys.path.insert(0,"project-management/watchdog"); import coordinator,evidence_policy; s=json.load(open("project-management/watchdog/fixtures/scoped-admission/synthetic-snapshot.json")); print(json.dumps(coordinator.evaluate(s,evidence_policy.utc(s["observed_at"])),indent=2))'

An ordinary current-clock CLI invocation correctly rejects this old fixture as
stale. Never reset a fixture timestamp and call it a live collection.

`replay_real_docs.py` pins the original authority/submission semantic digests and
runs the unchanged evidence-policy evaluator and the scoped coordinator at the

authorization receipts are deliberately synthetic isolation scaffolding. It
checks that such receipts say SYNTHETIC. The positive result means the real

complete current live inventory or permission to merge PR430.

The negative input uses the actually observed 19:11 current-rule authority,
retaining the author's historical acknowledgment. It produces

rewrites an acknowledgment, refreshes an attestation, or infers game acceptance.

refs; that still does not turn this historical replay into current admission.

After materializing those authorized inputs privately, run:

    python3 project-management/watchdog/fixtures/scoped-admission/replay_real_docs.py --snapshot /private/control-snapshot.json --negative-authority /private/observed-authority.json --negative-objects /private/observed-objects.json

## Bounded read-only rule-pin correction

The first reviewed source treated canonical rule pins as automatic conflict
regions. Actual central PR143 exposed a false positive for docs-only readers.
The correction separates current authority pins from actual source/write/owner
regions. Every explicitly declared region remains protected, canonical evidence
source paths remain mandatory, and computed candidate rule writes cannot be
omitted. Current rule membership, author acknowledgment and independent review
still bind the exact current base. No unrelated/read-only caller flag is used.

`rule-proposal-controls.json` and its compressed Git proof retain actual public
PR143/PR377/Tokyo PR533 objects. They exercise source-delta and region-equivalence
primitives only, not full ancestry or live admission: PR143 changes four rule
documents, PR377 changes shared board context, and Tokyo PR533 changes the actual
td-218 task file. The latter two remain negative controls. Separate full-route
synthetic tests cover PR143-shaped rule readers, candidate rule writers, explicit
rule dependencies, changed pins/ACKs, owners, queues and wildcard stops. No
private collector inventory or observations are published.
